# 🌦️ Local Weather Prediction & Correction Pipeline

## 📖 Overview
This project implements an end-to-end Machine Learning pipeline to predict and correct temperature forecasts for **Lagoa do Ouro, PE**.

By training a **Random Forest Regressor** on 2 years of local historical data, this system learns the specific micro-climate biases of the region. It then uses this "brain" to refine the standard global forecasts provided by the Open-Meteo API, acting as a local correction layer.

## 🚀 Key Features
* **Automated ETL:** Fetches historical hourly weather data (Temp, Humidity, Wind, Rain) from the Open-Meteo Archive API.
* **Feature Engineering:** Transforms raw timestamps into cyclical features (Hour, Month, Day of Year) to capture seasonal and daily trends.
* **Machine Learning:** specific Random Forest model (MAE: ~0.44°C) that beats standard sensors in precision.
* **Live Inference:** Fetches live forecasts for the next 3 days and applies the ML model to generate "Corrected" temperature predictions.
